# 01 · 项目概述与快速开始

## 1. 项目定位

Webnovel Writer（v6.2.1）是一个 **Claude Code 插件形式的长篇网文创作系统**。它要解决的核心问题不是"写出第一章"，而是写到第 80 章、第 200 章以后仍然保持：

- 角色动机不漂移
- 战力、时间线、地点和世界规则不互相打架
- 伏笔有登记、有推进、有回收
- 爽点、感情线、世界观扩展保持节奏
- 每章写完后事实沉淀到可检索的状态系统

实现方式是把"必须记住、不能写崩"的约束变成 Claude Code 自动执行的步骤：**动笔前查资料 → 写完登记事实 → 一致性审查 → 同步进检索索引/摘要/长期记忆/Dashboard**。

### 分支导览

| 分支 | 版本 | 状态 |
|------|------|------|
| `master`（本仓库） | v6 · Claude Code 插件 | 维护中（只修致命 bug），Claude Code 用户使用 |

## 2. 核心能力（8 个斜杠命令）

| 能力 | 命令 | 说明 | 文档 |
|------|------|------|------|
| 深度初始化 | `/webnovel-init` | 分阶段问答搭建项目骨架、设定集、总纲与初始状态 | [04](04-Skills命令详解.md) |
| 卷纲规划 | `/webnovel-plan <卷号>` | 拆卷纲、节拍表、时间线、批量章纲，并写回新增设定 | [04](04-Skills命令详解.md) |
| 章节创作 | `/webnovel-write <章号>` | 一条龙：备上下文 → 起草 → 审查 → 润色 → 提交 → 备份 | [04](04-Skills命令详解.md) |
| 质量审查 | `/webnovel-review <范围>` | 多维度审查章节并把指标落库 | [04](04-Skills命令详解.md) |
| 状态查询 | `/webnovel-query <关键词>` | 查询角色、伏笔、节奏、实体关系与运行时信息（只读） | [04](04-Skills命令详解.md) |
| 项目学习 | `/webnovel-learn "<经验>"` | 把有效写法沉淀进项目长期记忆 | [04](04-Skills命令详解.md) |
| 可视化面板 | `/webnovel-dashboard` | 只读浏览项目状态、实体图谱、章节内容与追读力数据 | [09](09-Dashboard详解.md) |
| 项目体检 | `/webnovel-doctor [--chapter N]` | 阶段感知检查目录、文件、数据库、RAG、依赖与 Dashboard 产物 | [04](04-Skills命令详解.md) |

## 3. 技术栈概览

| 层 | 技术 | 用途 |
|----|------|------|
| 插件宿主 | Claude Code Plugin（skills + agents + hooks） | 对话式命令分发与子代理 |
| 后端脚本 | Python ≥ 3.10（aiohttp / filelock / pydantic） | CLI 工具链、数据链、RAG、长期记忆 |
| Dashboard 后端 | FastAPI + uvicorn + watchdog + httpx | 只读 API + SSE 实时推送 |
| Dashboard 前端 | React 19 + react-router-dom 7 + ECharts 5 + Vite 6 | 像素风可视化面板（预打包 dist 随插件发布） |
| 存储 | JSON（state/contract/commit）+ SQLite（index.db / vectors.db）+ Markdown（章节/摘要/审查） | 分层持久化 |
| 知识库 | 9 张 CSV（BM25 检索）+ 37 个题材模板 + 方法论 Markdown | 题材与写法知识 |

## 4. 仓库顶层结构

```text
webnovel-writer/                 # 仓库根
├── .claude-plugin/              # Marketplace 清单（插件源指向 ./webnovel-writer）
├── .github/                     # CI：版本一致性检查 + 发布流水线
├── docs/                        # 官方文档中心（architecture/guides/operations/...）
├── releases/                    # 各版本 Release Notes
├── pytest.ini                   # 测试入口（pythonpath 指向 scripts/）
├── requirements.txt             # 汇总依赖（scripts + dashboard）
├── sitecustomize.py             # 测试环境定制
└── webnovel-writer/             # ★ 插件源目录（安装包本体）
    ├── .claude-plugin/plugin.json
    ├── agents/                  # 4 个子代理定义（md）
    ├── skills/                  # 8 个斜杠命令定义（SKILL.md + references）
    ├── hooks/                   # SessionStart / PreToolUse 运行时防护
    ├── references/              # 共享参考：9 张 CSV + 方法论 md + schema
    ├── templates/               # 37 题材模板 + init/plan 产物骨架
    ├── scripts/                 # ★ Python 工具链（CLI + data_modules）
    │   ├── webnovel.py          # CLI 统一入口（薄封装）
    │   ├── data_modules/        # 核心数据模块（约 80 个模块 + memory/ 子包 + tests/）
    │   └── *.py                 # 章节提交/状态更新/备份等根目录脚本
    └── dashboard/               # FastAPI 只读后端 + React 前端（预打包 dist/）
```

详细目录注释见 [03-模块与目录结构](03-模块与目录结构.md)。

## 5. 快速开始（使用视角）

### 5.1 安装插件

```bash
# 通过 Claude Code Marketplace 安装（推荐，user 级）
claude plugin marketplace add lingfengQAQ/webnovel-writer --scope user
claude plugin install webnovel-writer@webnovel-writer-marketplace --scope user

# 只在当前项目生效时把 --scope user 改成 --scope project
```

### 5.2 安装 Python 依赖

```bash
python -m pip install -r https://raw.githubusercontent.com/lingfengQAQ/webnovel-writer/HEAD/requirements.txt
```

### 5.3 初始化一本书

在 Claude Code 中输入 `/webnovel-init`，完成后创建的书项目目录：

```text
project-root/
├── .story-system/        # 合同、章节提交和事件审计（唯一事实主链）
├── .webnovel/            # 状态、索引、摘要、备份和长期记忆（投影/读模型）
├── 正文/                  # 章节正文
├── 大纲/                  # 总纲、卷纲、时间线和章纲
├── 设定集/                # 世界观、角色、力量体系等设定
└── 审查报告/              # 章节审查报告
```

### 5.4 配置 RAG（可选）

在书项目根目录 `.env`（复制自 `.env.example`）中最小配置：

```bash
EMBED_BASE_URL=https://api-inference.modelscope.cn/v1
EMBED_MODEL=Qwen/Qwen3-Embedding-8B
EMBED_API_KEY=your_embed_api_key

RERANK_BASE_URL=https://api.jina.ai/v1
RERANK_MODEL=jina-reranker-v3
RERANK_API_KEY=your_rerank_api_key
```

> 没填 Embedding Key 也能用——系统自动退回 BM25 关键词检索，只是语义召回弱一些。Embedding/Rerank 均可换成任何 OpenAI 兼容接口。详见 `docs/guides/rag-and-config.md`。

### 5.5 开始创作

```bash
/webnovel-plan 1      # 规划第 1 卷
/webnovel-write 1     # 写第 1 章
/webnovel-review 1-5  # 审查第 1-5 章
/webnovel-query 伏笔  # 查询项目状态
/webnovel-dashboard   # 打开可视化面板（浏览器 http://127.0.0.1:8765）
```

### 5.6 CLI 直接调用

所有命令行工具统一从 `scripts/webnovel.py` 进入：

```bash
python -X utf8 "<CLAUDE_PLUGIN_ROOT>/scripts/webnovel.py" --project-root "<PROJECT_ROOT>" <子命令> [参数]
```

常用子命令：`where` / `preflight` / `project-status` / `doctor` / `write-gate` / `projections` / `story-system` / `chapter-commit` / `story-events` / `memory` / `rag` / `status`。完整清单见 [06-CLI 工具链详解](06-CLI工具链详解.md)。

### 5.7 排查问题

优先执行预检与体检：

```bash
python -X utf8 "<CLAUDE_PLUGIN_ROOT>/scripts/webnovel.py" --project-root "<PROJECT_ROOT>" preflight
python -X utf8 "<CLAUDE_PLUGIN_ROOT>/scripts/webnovel.py" --project-root "<PROJECT_ROOT>" doctor --format text
```

重点查看：`story_runtime.mainline_ready` 是否为 true；`.story-system/commits/chapter_XXX.commit.json` 是否 accepted；`projection_status` 是否全部 `done/skipped`；`index.db`、`summaries/`、`memory_scratchpad.json` 是否正常生成；RAG Key 是否写入书项目根 `.env`。
