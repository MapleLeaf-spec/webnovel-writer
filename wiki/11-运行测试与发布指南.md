# 11 · 运行、测试与发布指南

## 1. 环境准备

### 1.1 版本要求

| 依赖 | 要求 |
|------|------|
| Python | >= 3.10（CI 使用 3.11） |
| Claude Code | 支持 Plugin 的版本（宿主） |
| Node.js | 仅开发 Dashboard 前端时需要（≥18） |

### 1.2 安装依赖

```bash
# 开发仓库
python -m pip install -r requirements.txt
python -m pip install -r webnovel-writer/scripts/requirements.txt
python -m pip install -r webnovel-writer/dashboard/requirements.txt

# 前端依赖（仅开发 Dashboard）
cd webnovel-writer/dashboard/frontend
npm install
```

> 根 `requirements.txt` 只是 `-r` 汇总两份 requirements，不会重复安装。

## 2. 测试

### 2.1 运行全量测试

```bash
# 在仓库根目录
python -m pytest
```

**测试行为由 pytest.ini 定义**：

```ini
[pytest]
testpaths = webnovel-writer/scripts/data_modules/tests webnovel-writer/scripts/tests
pythonpath = webnovel-writer/scripts
asyncio_mode = auto
addopts = -p no:debugging -p pytest_cov -q --cov --cov-report=term-missing --cov-fail-under=90 -p no:cacheprovider
```

关键点：
- 覆盖对象：`scripts/data_modules`（.coveragerc），**覆盖率门槛 90%**（`--cov-fail-under=90`），低于门槛测试失败
- `asyncio_mode = auto`：异步测试无需手动装饰器
- 常用参数：单测 `pytest tests/test_config.py -q`；看覆盖缺口 `pytest --cov-report=term-missing | grep -A2 "Missing"`；跳过覆盖 `pytest --no-cov`

### 2.2 测试目录

| 目录 | 内容 |
|------|------|
| `webnovel-writer/scripts/data_modules/tests/` | 单测（≈90 个文件，与 data_modules 模块一一对应） |
| `webnovel-writer/scripts/tests/` | 集成/工具测试（hooks、dashboard 安全、reference_search、backup、evals、发布校验） |
| `webnovel-writer/evals/fixtures/`、`skills/*/evals/` | 行为评估用例（`run_behavior_evals.py` 执行，非 pytest） |

### 2.3 行为评估（非 pytest）

```bash
python webnovel-writer/scripts/run_behavior_evals.py
```

用于验证 Skill 行为的规范执行，读 `evals/evals.json`（Agent 输出打点评估）。

### 2.4 Windows 测试

```powershell
.\webnovel-writer\scripts\run_tests.ps1
```

## 4. 发布流程（CI）

### 4.1 版本一致性（plugin-version.yml）

`push/PR` 触发（路径：marketplace.json / plugin.json / sync_plugin_version.py / validate_release_notes.py / README / CHANGELOG / releases）：

```bash
python webnovel-writer/scripts/sync_plugin_version.py --check     # 版本一致性
python webnovel-writer/scripts/validate_release_notes.py          # Release Notes 校验
```

### 4.2 发布（plugin-release.yml）

`push master`（上述路径变更）或手动 `workflow_dispatch`（可指定 version）触发，步骤：

```bash
1. checkout + setup-python 3.11
2. sync_plugin_version.py --check --expected-version <V>
3. validate_release_notes.py --version <V>
4. validate_plugin_package.py          # 插件包完整性（dist、skill、agent、hooks、脚本聚合）
5. 校验 tag 是否存在 → git tag v<V> → push
6. 校验 GitHub Release 是否存在 → softprops/action-gh-release 发布，body 取 releases/v<V>.md
```

### 4.3 手工发版备忘

```text
1. 更新 webnovel-writer/.claude-plugin/plugin.json + .claude-plugin/marketplace.json 的 version
2. 新增 releases/vX.Y.Z.md（含变更内容）
3. 更新 CHANGELOG.md / 根 README 版本徽标与表格
4. 本地跑 sync_plugin_version.py --check 与 validate_release_notes.py
5. push master ✓（CI 自动打 tag 发 Release）
```

### 4.4 发布前完整性检查点

```bash
python -m pytest                      # 覆盖率 ≥90%
python webnovel-writer/scripts/validate_csv.py                # CSV 校验
python webnovel-writer/scripts/validate_plugin_package.py     # 打包校验
python webnovel-writer/scripts/validate_release_notes.py      # 版本说明
```

> clean-room 验证建议：用 `git archive` 或干净克隆，避免本地 `node_modules/__pycache__/.coverage` 污染 `validate_plugin_package.py`。

## 5. 常见问题速查

| 症状 | 排查 |
|------|------|
| 覆盖率低于 90% 测试失败 | `pytest --cov-report=term-missing` 查看缺口，为新代码补测试 |
| preflight `mainline_ready=false` | `.story-system` 合同缺失（跑 `story-system --persist`）或 fallback_sources 非空 |
| 写章在中途失败重复执行重写 | 用 `webnovel.py run-ledger write-resume --chapter N` 看断点建议 |
| 投影失败 | `webnovel.py projections retry --chapter N`；仍失败查 `.webnovel/projection_log.jsonl` |
| hooks 拦截了自己的写入 | 不要直接改 commits/、index.db、vectors.db、memory_scratchpad、projection_log——走官方 CLI |
| Dashboard 页面不刷新 | 检查是否在写 `.webnovel{state.json,index.db}` 或 `.story-system/**/*.json`（watcher 只监听这些） |
| Windows 写章报拒绝访问（WinError 5） | 资料文件被短暂占用，v6.2.1 已自动重试；可重跑该章 |
| RAG 检索弱 | 检查 `.env` 的 EMBED_/RERANK_ 配置；无 key 时是预期行为（BM25 降级） |
