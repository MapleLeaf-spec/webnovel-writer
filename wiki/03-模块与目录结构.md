## 3. skills 子目录通用结构

每个 skill 由 `SKILL.md`（frontmatter：`name` / `description` / `allowed-tools` + 正文流程）+ 私有 `references/`（可选）组成：

```text
skills/webnovel-write/
├── SKILL.md                      # frontmatter + 完整步骤链 + 充分性闸门 + 报告契约
├── evals/evals.json              # 该 skill 的行为评估用例（run_behavior_evals.py）
└── references/
    ├── polish-guide.md           # 润色指南（区段读）
    ├── anti-ai-guide.md          # Anti-AI 终检
    ├── style-adapter.md          # 文风适配
    └── writing/                  # combat-scenes / dialogue-writing / emotion-psychology / scene-description / typesetting
```

## 4. scripts/ Python 工具链

### 4.1 顶层一览

```text
scripts/
├── webnovel.py                   # CLI 统一入口（薄封装：把 scripts/ 加入 sys.path → 转发 data_modules.webnovel.main()）
├── requirements.txt              # aiohttp / filelock / pydantic（运行）+ pytest*（测试）
```

## 5. data_modules/ 核心数据模块（分组速查）

按职责分组（约 80 个模块）：

| 分组 | 模块 | 一句话职责 |
|------|------|-----------|
| CLI 分发 | `webnovel.py` | argparse 主入口，子命令 → 模块/脚本转发 |
| 配置 | `config.py` | `DataModulesConfig` dataclass：路径布局 + API/RAG/预算参数 + .env 加载 |
| Schema | `schemas.py` | Data Agent 输出契约（DataAgentOutput 等）+ 校验/归一 |
| 合同引擎 | `story_system_engine.py` | 题材 query → 种子契约（Master Setting + Chapter Brief + Anti-patterns） |
| 合同模型 | `story_contract_schema.py` / `story_contracts.py` / `runtime_contract_builder.py` | 合同 pydantic 模型 / 路径与持久化 / 运行时合同组装 |
| 提交链 | `chapter_commit_service.py` / `chapter_commit_schema.py` / `commit_artifacts.py` | 提交领域服务 / 4 artifact 校验 / 访问器 |
| 事件链 | `story_event_schema.py` / `event_log_store.py` / `event_projection_router.py` / `override_ledger_service.py` / `amend_proposal_schema.py` | 10 种事件 / 双写日志 / writer 路由 / 修订提案 |
| 状态双写 | `state_manager.py` / `sql_state_manager.py` / `migrate_state_to_sqlite.py` / `state_validator.py` | state.json 读写 + SQLite 镜像 / 迁移 / 校验 |
| 索引 | `index_manager.py` + 5 个 `index_*_mixin.py` | index.db 唯一读写入口（章节/场景/实体/关系/债务/追读力/可观测性） |
| 投影 | `projections.py` / `projection_log.py` + 5 个 `*_projection_writer.py` | 补跑/重放 + JSONL 账本 + state/index/summary/memory/vector 写入器 |
| 记忆 | `memory/` 子包（schema/store/writer/orchestrator/budget/compactor/bootstrap） | 长期记忆全生命周期 |
| RAG | `rag_adapter.py` / `api_client.py` / `query_router.py` / `knowledge_query.py` | 向量+BM25+图谱检索 / Embedding/Rerank 客户端 / 意图路由 / 章节时点知识 |
| 上下文 | `context_manager.py` / `context_ranker.py` / `context_weights.py` | 写前上下文包组装（16 段契约 v3）/ 重排 / 模板权重 |
| 审查配套 | `review_schema.py` / `review_author_view.py` / `run_ledger.py` / `run_logger.py` | 审查解析 / 作者视角渲染 / 断点账本 / 脱敏日志 |
| 体检 | `doctor.py` / `project_status.py` / `project_phase.py` / `story_runtime_health.py` / `story_runtime_sources.py` | 只读体检 / 短状态 / 阶段感知 / 运行态健康 / 来源快照 |
| 验证 | `prewrite_validator.py` / `placeholder_scanner.py` / `entity_linker.py` / `artifact_validator.py` / `write_gates/`（prewrite/precommit/postcommit） | 写前阻断 / 占位扫描 / 实体消歧 / artifact 校验 / 三道关卡 |
| 题材与写作 | `genre_aliases.py` / `genre_profile_builder.py` / `writing_guidance_builder.py` / `style_sampler.py` / `urgency_utils.py` / `review_author_view.py` | 题材别名 / 画像 / 写作指导+检查清单 / 风格采样 / urgency 归一 |
| 可观测性 | `observability.py` | 永不抛异常的工具调用统计/性能计时 |
| 其他 | `memory_contract.py` / `memory_contract_adapter.py` / `projections.py` 等 | 记忆合同适配 / 投影编排 |
